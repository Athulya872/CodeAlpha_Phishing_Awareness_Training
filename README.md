
# CodeAlpha - Phishing Awareness Training

## Project Overview

Phishing Awareness Training is a beginner-friendly cybersecurity
awareness website developed as part of the CodeAlpha Cyber Security
Internship.

The project educates users about phishing attacks, explains how to
recognize suspicious messages and websites, and provides practical
tips to stay safe online.

## Objectives

- Understand phishing and its common forms.
- Identify warning signs in suspicious emails and messages.
- Learn how to recognize potentially suspicious website domains.
- Understand safe online practices.
- Test cybersecurity awareness through an interactive quiz.

## Features

### 1. Phishing Awareness
Provides an introduction to phishing and explains common types,
including email phishing, smishing, and vishing.

### 2. Warning Signs
Explains common indicators of phishing, such as urgent messages,
suspicious links, unexpected attachments, and requests for sensitive
information.

### 3. Phishing Email Demonstration
Displays a sample phishing scenario to help users understand
common phishing warning signs.

### 4. Basic Domain Checker
Checks user-entered domains against a small set of suspicious patterns.
This is an educational demonstration and does not verify a website's
actual safety.

### 5. Interactive Quiz
Allows users to answer multiple-choice questions and receive a score
based on their answers.

### 6. Responsive Design
Uses CSS to provide a layout suitable for desktop computers,
tablets, and mobile devices.

## Tools and Technologies Used

- **HTML5:** Structures the website content.
- **CSS3:** Styles the website and supports responsive layouts.
- **JavaScript:** Implements interactive demonstrations, domain
  pattern checks, and quiz functionality.
- **Visual Studio Code:** Used to create and edit project files.
- **Live Server Extension:** Used to run and test the website locally.
- **Git and GitHub:** Used for version control and project hosting.

## How to Run the Project

1. Download or clone the project repository.
2. Open the project folder in Visual Studio Code.
3. Ensure all four project files are present.
4. Install the Live Server extension if it is not already installed.
5. Open `index.html`.
6. Right-click the file and select **Open with Live Server**.
7. Explore the website, try the phishing demonstration, test the
   domain checker, and complete the quiz.

## Learning Outcomes

- Improved understanding of phishing attacks and social engineering.
- Ability to identify common phishing warning signs.
- Basic knowledge of website domain inspection.
- Practical experience with HTML, CSS, and JavaScript.
- Experience creating an interactive cybersecurity awareness website.

## Limitations

The domain checker uses predefined patterns and is not a comprehensive
phishing detection system. A domain that passes the check may still
be malicious.

The project is intended for cybersecurity education and awareness.
It does not collect credentials, send emails, or perform real phishing
attacks.
